# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Paper Engine: an early-stage C++23 Vulkan 1.3 engine (CMake project `myengine`). Targets (ADR 0012, plan in `docs/plan/`): `base` (header-only: `Error`, glm, spdlog), `core` (engine static library, namespace `Paper`), `game` (shared headless simulation), `net` (protocol/transport), `sandbox` (drives `core`), `client` and `server` (game executables; `server` must stay free of Vulkan/GLFW and links only `game` + `net`). `game` depends only on `base`; `net` depends on `base` and `game` (it serializes game types). Private GitHub repo (`J4m3s00/paperengine`); no tests or linter configured yet.

## Commands

Requires CMake ≥ 3.28, Ninja, ccache (used as compiler launcher in the presets), and the Vulkan SDK (`find_package(Vulkan COMPONENTS glslc)`). All other dependencies are fetched via FetchContent on first configure.

```
cmake --preset debug          # configure → build/debug (also: release → build/release)
cmake --build build/debug     # build
./build/debug/sandbox/sandbox # run
```

VS Code tasks ("build debug") and the LLDB launch config "Debug sandbox" wrap these. `.clangd` points at `build/debug/compile_commands.json`, so configure the debug preset before relying on clangd.

## Architecture

- `core/include/core/*.h` is the public header root (included as `"core/xxx.h"`); implementations are in `core/src/`. New `.cpp` files must be added to the `add_library(core ...)` list in `core/CMakeLists.txt` (no globbing).
- Dependency visibility matters: `glfw`, `glm`, `spdlog`, `Vulkan` are PUBLIC; `vk-bootstrap` and VMA are PRIVATE. Headers must therefore not include `VkBootstrap.h` or `vk_mem_alloc.h`; `vulkan_context.h` forward-declares `VmaAllocator`. `GLFW_INCLUDE_NONE` is defined for core.
- VMA is compiled once in `src/vma_impl.cpp` (`VMA_IMPLEMENTATION`); other TUs include `vk_mem_alloc.h` with `VMA_VULKAN_VERSION 1003000` defined the same way. Its include dirs are added as SYSTEM to silence third-party warnings.
- Errors are `std::expected<T, Paper::Error>` (`base/error.h`, see `docs/adr/0001-expected-for-error-handling.md`). Fallible types (`Window`, `VulkanContext`, `Swapchain`) have private constructors and a static `create(...)` returning `std::expected<std::unique_ptr<T>, Error>`; they stay non-copyable/non-movable. vk-bootstrap results are translated by `unwrap` in `core/src/vkb_error.h`.
- `Window` uses pimpl (GLFW details hidden in `Window::Impl`), exposes `nativeHandle()` for surface creation.
- `VulkanContext` owns instance, debug messenger, surface, physical/logical device, queues and VMA allocator, built via vk-bootstrap. Requires Vulkan 1.3 with `dynamicRendering` and `synchronization2`. Validation layers default on unless `NDEBUG`. Non-copyable/non-movable; must outlive everything created from it.
- `Swapchain` borrows `const VulkanContext&` and builds images/views; `recreate(window)` returns `expected<bool, Error>`: `false` (keeping the old swapchain) while the framebuffer is 0×0. The sandbox loop currently triggers `recreate` by comparing framebuffer size to swapchain extent.
- `Renderer` (`core/renderer/renderer.h`, pimpl) is the public entry point: `Renderer::create(window)` builds `VulkanContext` and `Swapchain` itself and `render()` draws one frame (2 frames in flight, dynamic rendering, per-swapchain-image render-finished semaphores, resize handled internally). `sandbox` only holds `Window` and `Renderer`; the `Window` must outlive the `Renderer`.
- Shaders: GLSL in `core/shaders/`, listed in `PAPER_SHADER_SOURCES` in `core/CMakeLists.txt` and compiled by `glslc` to `<build>/shaders/<name>.spv` (target `core_shaders`, a dependency of `core`). `Shader::load` reads a `.spv`; `RendererConfig::assetRoot` locates the `shaders/` folder (default: `<exe dir>` if it has `shaders/`, else the build dir via `PAPER_DEFAULT_ASSET_ROOT`). New shaders must be added to that list. `pbr.frag` shows the conventions (set 1 `Material` block, texture slots, `ALPHA_MASK` constant); shared GLSL goes in `core/shaders/include/` (`#include`, tracked via glslc depfiles).
- Rendering: `Renderer::render(scene, camera)` draws every entity with `WorldTransform` + `MeshRenderer {mesh, material}`, sorted by (pipeline, material). Set 0 = per-frame UBO (`FrameUniforms`, one per frame in flight), set 1 = per-material UBO, per-object `PushConstants` (model + normal matrix, 128 bytes), fixed `Vertex` layout (`core/renderer/mesh.h`). Depth buffer is `D32_SFLOAT`, shared by all frames in flight (a barrier orders it). Viewport has negative height (Y up), front face counter-clockwise, depth 0..1 (`glm::perspectiveRH_ZO`).
- Materials (ADR 0003-0005): `createShader({vert.spv, frag.spv})` loads and reflects the SPIR-V (SPIRV-Reflect, PRIVATE; `shader_reflection.cpp`) and validates the engine conventions: vertex inputs must match locations 0..3, set 0 is reserved, set 1 may only hold a uniform block at binding 0 plus `sampler2D` slots at bindings >= 1. `createMaterial(shader, RenderState)` allocates one UBO + descriptor set per frame in flight; `setMaterialParam(material, "name", value)` is validated against the reflected block (unknown name / wrong type returns an `Error`) and marks the UBO copies dirty. `RenderState` = cull mode, alpha mode (OPAQUE/MASK; MASK is passed as specialization constant 0 `ALPHA_MASK`), depth test. Pipelines are created lazily and cached by (shader, render state, color/depth format) in `Renderer::Impl::getPipeline`.
- Lighting (ADR 0008): `pbr.vert/frag` is the standard glTF metallic-roughness shader. Lights are entities with `DirectionalLight` (shines along local -Z; use `lookRotation`), plus `Scene::ambientLight`; `Renderer::render` packs up to 8 lights into the set 0 uniform block (`include/frame.glsl` must match `FrameUniforms` in `renderer.cpp`). No shadows, no IBL, no tone mapping. New materials start with all parameters zero.
- Screenshots: `Renderer::requestScreenshot(path)` saves the next rendered frame as a PNG (waits for the GPU); the sandbox exposes it as `--screenshot out.png` (renders 30 frames, saves, exits), handy for checking rendering without a display.
- Textures (ADR 0006): `stb_image` (single header fetched at a pinned commit) decodes in `core/assets/image.h`; `Renderer::createTexture/loadTexture` upload RGBA8 with a mip chain (`uploadTexture` in `gpu_resources.cpp`) in `ColorSpace::Srgb` (base color, emissive) or `Linear` (everything else). Shaders declare `layout(set = 1, binding = N) uniform sampler2D name;` (N >= 1, max 8); `setMaterialTexture(material, "name", texture)` assigns it. Unassigned slots use default textures (white; flat normal for names containing "normal"). Samplers are cached by `SamplerSettings`; `samplerAnisotropy` is a required device feature.
- Resources: meshes, shaders, materials and textures are `Handle<Tag>` (index + generation, `ResourcePool` in `core/src/renderer/resource_pool.h`) owned by the Renderer. `destroy*` does not free immediately: the object goes into a deletion queue and is released once the frames that may still use it have finished (`retire`/`collectGarbage` in `renderer.cpp`). `destroyShader` requires that no live material uses it. Uploads are synchronous (staging buffer, graphics queue). Internal GPU wrappers (`GpuBuffer`, `GpuImage`, `uploadBuffer`) are in `core/src/renderer/gpu_resources.h`.
- glTF (ADR 0007): `Renderer::loadModel(path, shader)` imports `.gltf`/`.glb` via fastgltf (`core/src/assets/gltf_loader.cpp`, uses only the public Renderer API) into a `Model` (`core/assets/model.h`); `scene.instantiate(renderer.model(handle))` spawns the entities (one per node, plus a child per primitive with a `MeshRenderer`). glTF material properties map by name onto the shader's parameters/slots (`baseColorFactor`, `metallicFactor`, … / `baseColorTexture`, …); unknown names are skipped. `destroyModel` frees the model's meshes/materials/textures. Run the sandbox with a path to view a model: `./build/debug/sandbox/sandbox model.glb` (no argument = demo cubes).
- Scene: `core/scene/` — `Scene` wraps `entt::registry` (EnTT is a PUBLIC dependency); components in `components.h` (`Transform`, `Relationship`, `WorldTransform`, `MeshRenderer`); use `Scene::setParent` for the hierarchy and call `TransformSystem::update(scene)` before `render`. `Camera` is a standalone struct passed to `render`.
- Input: `Window` exposes polled state refreshed by `update()` — `keyDown`, `mouseDown`, `mousePosition`, `mouseDelta`, `scrollDelta`, `setCursorMode`, `requestClose` (enums in `core/input.h`, mapped to GLFW codes in `window.cpp`; add keys there as needed). No event system. The fly camera controller lives in `sandbox/fly_camera.h`, not in `core`.
- Private headers live in `core/src` (on the private include path): `vkb_error.h`, `vk_check.h`.
- `core/src/engine.cpp` and `core/include/core/engine.h` are placeholders (essentially empty).

- Profiling: `PAPER_ENABLE_PROFILER` (ON in the debug preset, OFF in release) compiles in Tracy (on-demand, so it costs nothing until the viewer connects). Use `PAPER_ZONE("name")` and `PAPER_FRAME_MARK()` from `base/profiler.h`; they compile to nothing when off.
- Debug UI: Dear ImGui (v1.93, built in `core/CMakeLists.txt`; GLFW + Vulkan dynamic-rendering backends in `core/src/renderer/imgui_layer.cpp`) is owned by the Renderer. `Renderer::setUiCallback(fn)` runs `fn` each frame and draws it over the scene; `uiWantsMouse/Keyboard()` tell the app to ignore input. `DebugOverlay` (`core/debug/debug_overlay.h`) shows frame times, avg/1% low FPS and live-editable cvars; the sandbox toggles it with F1 (and shows it in `--screenshot` runs).
- Collision (`game/collision.h`, ADR 0010): Source units, Y up. `CollisionWorld::create(brushes)` builds a BVH over convex brushes (planes, outward normals) and adds bevel planes so an axis-aligned `Hull` sweep is exact; `traceHull`/`traceRay`/`pointSolid` are allocation-free (~230 ns per short trace over 2000 brushes, release). Triangle meshes are not supported yet.
- Movement (`game/movement.h`): `movePlayer(PlayerState&, UserCmd, CollisionWorld, MovementParams, maxSpeed, dt)` is a port of Source's `FullWalkMove` (half gravity before/after, friction only on ground, `AirAccelerate` with the 30 u/s cap, `TryPlayerMove` plane clipping, `StepMove`, no auto-bhop, CS:GO jump speed cap behind `sv_enablebunnyhopping`). `MovementCvars` registers `sv_accelerate`, `sv_airaccelerate`, ... and builds a `MovementParams`. Yaw 0 looks along -Z. A hull exactly touching a surface counts as starting inside it, so spawn points need a small gap above floors. Not yet ported: edge friction, crouch transition time, ladders, water.
- Maps (`game/map.h`): JSON v1 (`maps/dev_world.json`): `brushes` (`box`, `ramp` with low/high/rising direction, raw `planes`, optional `material`) and `entities` (`spawn`, `bot`, ... with `origin`/`yaw` degrees). `loadMap` → `MapData::buildCollision()`. `brushFaces()` (`game/brush_geometry.h`) clips planes into render polygons; `client/world_mesh.cpp` turns them into per-material meshes with world-space planar UVs. The `client` target loads the map (`--map`, default dev world; `--screenshot out.png`).
- Replays (`game/replay.h`): a `Replay` is start state + movement params + one `UserCmd` per tick (+ expected end state); `runReplay` re-simulates it headless. `client --record out.replay.json` records a session. Golden replays in `game/tests/replays/` are replayed by `game_tests`; after an intentional movement change re-bless them with `PAPER_UPDATE_REPLAYS=1 ./build/debug/game/game_tests -tc="replay golden: movement*"` and review the diff.
- Tests: doctest in `game/tests` (`ctest --preset debug`). Cvars (`base/cvar.h`): typed, clamped, settable from strings/config files; game code registers them on `Paper::cvars()`.

- Netcode (`net/`, ADR 0009/0013): `Transport` (ENet: `EnetTransport`; tests: `LoopbackNetwork` with a seeded conditioner; `ConditionedTransport` wraps any transport). `protocol.h`: bit-packed messages, delta snapshots against the last acked baseline. `Server` (headless, no clock/sockets: call `tick()` at 128 Hz) and `ClientSession` (prediction + reconciliation + interpolation; per tick call `tick(input)`). Usercmds are quantized on the wire; the client predicts with `quantizeUserCmd`. Tests: `net_tests`. Executables: `server` (dedicated), `bots` (`--inprocess` soak or `--connect` over UDP), `client --connect host:port [--lag RTT --jitter ms --loss p]`.

- Combat (ADR 0011, 0014): weapons are JSON in `weapons/` (`WeaponDb`); `game/weapon.h` `stepWeapon` is the shared fire/reload/recoil/spread state machine (clock = usercmd seq). `game/hitbox.h` (`HitboxProvider`, `FixedHitboxProvider`) and `game/lag_compensation.h` (pose history + rewind). `net/server.h` resolves hitscan shots after all players moved (`resolveShot`), `addBot` adds server bots. Online client controls: mouse 1 fire, R reload, 1-7 weapons (offline respawn is T). `client/combat_view.h` has the placeholder effects and HUD. `audio/` is a separate library (miniaudio, `AudioEngine`, `Synth` placeholder sounds; `noDevice` mode for tests). The server and bots take `--weapons dir` / use `PAPER_WEAPONS_DIR`.

- Rules and menu (ADR 0015): `game/rules.h` has the pure `RoundManager` (team elimination), `RulesCvars` (`mp_*`), `restrictCmd`. `Server` runs it when `ServerConfig::teamplay` is set (teams, team spawns, freeze, no mid-round respawn, stats, `kickAll`, `takeMatchRestarted` for map rotation); snapshots carry `MatchState` and per-player `PlayerInfo`. Server flags: `--config server.cfg`, `--maps a,b,c`, `--set cvar value`. The client opens a menu without `--connect`/`--offline`; it does the Hello/Accept handshake itself, loads the map the server names, then continues in `ClientSession::adoptAccept`. Escape opens the pause menu, Tab shows the scoreboard.

- Editor (ADR 0016): `editor/` is the ImGui map editor (`./build/debug/editor/editor [map]`); its model is `game/map_edit.h` (`MapEditor`: edits, undo, picking, validation, headless-tested). `game/map.h` keeps brush kinds (box/ramp/planes) and has `serializeMap`/`saveMap`/`mapChecksum`; the server sends the checksum in `Accept` and the client rejects a mismatch. `mapc map.json` validates maps and prints the checksum. `mapview/` shares brush-to-mesh and the material palette between client and editor. Data folders resolve through `Paper::dataDir` (`base/paths.h`).

## Conventions

Compiler flags `${PAPER_WARNINGS}` apply to `core` only. Code style: 2-space indent, `m_` member prefix, `[[nodiscard]]` getters, deleted copy/move on RAII Vulkan wrappers (clang-format LLVM-like style).
